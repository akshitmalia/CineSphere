Filters user can apply:

Filter	Example values
Genre	Action, Comedy, Horror, Drama, Sci-Fi, Romance
Year	2024, 2023, 2022... all the way back
Language	English, Hindi, Korean, Spanish, French, Japanese
Min Rating	6+, 7+, 8+, 9+ (IMDb-style score from TMDb)

All filters work together — so user can say "Show me Hindi Action movies from 2023 rated 7+" and it works in one search. Each movie card shows poster, title, rating, year. Clicking a card goes to details page.

Complete user journey
Landing → clicks "Get Started"
  → Register/Login
    → Search page loads with trending movies by default
      → User applies filters (genre + year + rating)
        → Clicks a movie card
          → Movie details page (trailer, cast, info)
            → Clicks "+ Watchlist" → saved to MongoDB
              → Goes to Watchlist → sees all saved movies
                → Can remove any movie
